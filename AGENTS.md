# AGENTS.md

UniOne Rust SDK — client for the UniOne transactional email Web API (Web API 1.90).

## Working on this repository

- **Generated code.** The whole package is generated by the UniOne team from the UniOne Web API OpenAPI spec (Web API 1.90): sources, docs, README.md and this file. Do not hand-edit it: the next release replaces the content of this repository. Report problems and requests in the issues of this repository (https://github.com/unione-repo/unione-rust-sdk).
- **Build and check:**

  ```bash
  cargo build
  cargo clippy -- -D warnings
  ```

- **Source label.** Every request carries the query parameter `platform=rust-sdk.1.2.3`, added in one place, the shared request client (`ApiClient`); a package built on this SDK puts its own label in front: `<package>.<version>,rust-sdk.1.2.3`.
- **Tests.** Before a release the generator builds and lints the package and runs every example of docs/ and of this file against a mock of the API: no real API key, no real sends.
- **Release.** The version (1.2.3 in Cargo.toml) and the tag `v1.2.3` come from the generator; README.md states the Web API version the release was generated from.
- **Secrets.** Never commit API keys; the examples read `UNIONE_API_KEY` from the environment.

## Integrating UniOne with this SDK

Full quickstart: [README.md](README.md). Install:

```bash
cargo add unione-rust-sdk
cargo add tokio --features macros,rt-multi-thread
```

Requirements: Rust 1.70+ (edition 2021), async runtime (tokio).

If the project is built on one of these frameworks, install its package instead: it brings this SDK and plugs it into the framework (configuration, client in the container, mailer, webhooks).

| Framework | Package | Guide |
|---|---|---|
| axum | `unione-axum` | [AGENTS.md](https://github.com/unione-repo/unione-axum/blob/HEAD/AGENTS.md) |

Rules that generated code must follow:

- Server-side only. Read the API key from `UNIONE_API_KEY`; never put it in browser or mobile code, never commit it.
- Base URL `https://api.unione.io/en/transactional/api/v1` (an account registered on another host uses that one: `eu1.unione.io`, `us1.unione.io`); every method is POST with a JSON body; auth header `X-API-KEY`. The SDK does all of it.
- First email without DNS: `domain/get-sandbox-domain` → `confirmed-email/create` (the user clicks the link within 48 hours) → `email/send` from `noreply@<sandbox-domain>` to the confirmed address. Account API key only; up to 10 confirmed addresses, 100 emails a day; the domain expires after 31 days.
- Never ship a sandbox domain as the production sender (it is not in `domain/list`); read `from_email` from config. Production needs a verified domain: `domain/get-dns-records` → DNS records → `domain/validate-verification-record`, `domain/validate-dkim` → `domain/list`.
- Set `message.idempotence_key` on retryable sends; retry network errors, `429` and `5xx` with backoff, not other errors unchanged. Up to 500 recipients and 10 MB per request with the attachments in base64 (a third larger than the files); always `body.html` or `body.plaintext`.
- Delivery events via webhook (`webhook/set`) with a fast, idempotent HTTPS handler, not polling; check the `auth` field of every notification: the MD5 of the request body with the `auth` value replaced by the API key.
- Keep the default unsubscribe and tracking behaviour; changes go through UniOne support.
- Do not invent methods or fields. Check [docs/](docs/) of this package, the [API reference](https://docs.unione.io/en/web-api-ref) or [llms.txt](https://docs.unione.io/llms.txt).

### Send an email

The client reads the API key from `UNIONE_API_KEY`:

```rust
use std::collections::HashMap;
use unione::api::email::model::EmailSendRequest;
use unione::api::email::model::MessageObject;
use unione::api::email::model::MessageObjectRecipientsItem;
use unione::common::model::BodyObject;
use unione::UniOneClient;

#[tokio::main]
async fn main() -> Result<(), unione::ApiError> {
    let api_key = std::env::var("UNIONE_API_KEY").expect("set UNIONE_API_KEY");
    let client = UniOneClient::new(api_key);

    let response = client
        .email()
        .send(&EmailSendRequest {
            message: MessageObject {
                recipients: vec![MessageObjectRecipientsItem {
                    email: "user@example.com".to_string(),
                    substitutions: Some(HashMap::from([
                        ("CustomerId".to_string(), "12452".to_string()),
                        ("to_name".to_string(), "John Smith".to_string()),
                    ])),
                    ..Default::default()
                }],
                body: BodyObject {
                    html: Some("<b>Hello, {{to_name}}</b>".to_string()),
                    plaintext: Some("Hello, {{to_name}}".to_string()),
                    ..Default::default()
                },
                subject: "UniOne test email ".to_string(),
                from_email: Some("email@example.com".to_string()),
                from_name: Some("John Smith".to_string()),
                ..Default::default()
            },
        })
        .await?;
    println!("{:?}", response.job_id);
    Ok(())
}
```

### Errors

Every method throws `ApiError` when the request fails: the HTTP status (0 for a network error or a timeout), the [API error code](https://docs.unione.io/en/web-api-ref#api-errors) and the message.

```rust
// client created as above
if let Err(e) = client.system().ping() {
    // http_status is 0 for a network error or a timeout (e.is_timeout(), e.is_connect())
    eprintln!("{} {:?} {}", e.http_status, e.code, e.message);
}
```
